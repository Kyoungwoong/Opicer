# 시험장 특징 메모 (응시 후기 요약, 2026-10)

응시자들이 남긴 후기에서 시설에 관한 내용만 골라 새로 정리했다. 한두 명의 경험이라 날짜·좌석·시간대에 따라 다를 수 있다. 관리자 화면의 시험센터 설명을 쓸 때 참고하고, 앱 후기로 올리지 않는다.

| 시험장 | 좌석·칸막이 | 소음·헤드셋 | 그 밖에 |
|---|---|---|---|
| 강서 CBT (A·B) | 투명 유리 1인실, 시야 쪽은 가림. 조금 좁다는 의견도 있음 | 옆 사람 소리가 거의 들리지 않는다는 평이 많음. 헤드셋 사양은 평범하다는 의견 | 소리에 예민한 사람에게 추천한다는 후기가 여럿. 평일에는 응시자가 적었다는 기록 |
| 메이플넥스 역삼 (A) | 칸막이 있음. 공간이 좁다는 의견 | 노이즈캔슬링 헤드셋으로 바꿔 외부 소리가 거의 막힌다는 평과, 옆 사람 말이 들린다는 평이 섞임. 헤드셋이 커서 흘러내린다는 의견 | 근처 지하철 2호선 진동이 주기적으로 느껴짐(크게 거슬리지 않음) |
| 분당 오픽센터 | 2-2 배열, 자리마다 칸막이(앞은 투명, 옆은 책상 재질) | 스피커를 최대로 해도 옆 사람 소리가 잘 들린다는 의견 | |
| 대학로 공인시험센터 (혜화) | 좌석 간격이 촘촘하다는 의견과, 한 칸씩 띄워 여유 있었다는 의견 | | 문 밖에 시간대별 응시자 명단이 붙음. 입장 시간을 엄격히 관리해 몇 분 늦어 입장하지 못한 사례가 있음 |
| 강남 중국어학원 | | 주변 소리가 꽤 들린다는 의견 | 후기가 엇갈리나 쾌적했다는 평도 있음 |
| 영등포 (지하) | 칸막이 있음. 평일에는 좌석 간격이 넓었음 | 다른 응시자 소리가 잘 들리는 편. 헤드셋은 조금 오래됨 | 앞 시간 시험이 없으면 안에서 기다릴 수 있고 정수기가 있음 |
| 영통 오픽센터 (501호) | 한 줄에 4대, 가운데 통로. 칸막이 있음 | 바로 옆에 사람이 없으면 소리가 거의 들리지 않음. 11번 이후 음질이 조금 떨어졌다는 기록 | 시설은 보통 |
| 수원 SDA | 칸막이 있음 | 응시자가 많고 음질이 전반적으로 높지 않았다는 의견. 바깥 소리는 들리지 않음 | |
| 관악 CBT | | 다른 사람 말소리가 잘 들려 초반에 당황했다는 의견 | |

## 공통으로 나온 이야기

- 롤플레이(11~13번)에서 질문하는 목소리나 음량이 바뀌었다는 기록이 여러 시험장에서 나왔다. 시험장 설비보다는 시험 진행의 특징으로 보인다.
- 화면이 잠깐 멈추는 일이 있었다는 기록이 있다.
