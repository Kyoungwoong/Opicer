# 문항 은행 (2026-10)

실전연습과 주제별 연습이 쓰는 문항을 어떻게 정리했고, DB에 어떻게 넣는지 적는다. 문항 데이터 자체는 저장소에 두지 않는다. DB에 한 번 넣은 뒤에는 관리자 화면(주제 관리, 질문 관리, 설문 연결)에서 관리한다.

## 출처 원칙

- 응시자들이 기억으로 되짚은 메모(약 115회분)에서 **주제와 질문 유형의 경향만** 참고했다.
- 영어 문장은 Opicer가 직접 썼다. 공식 OPIc 문항이나 기출이라고 표시하거나 주장하지 않는다.
- 원본 메모는 다른 사람들의 기록이라 저장소에 올리지 않는다.

## 시험 흐름과 출제 규칙

메모에서 본 흐름은 대부분 같았다. 출제 규칙(`MockTestComposer`, `docs/opic/mock-test-spec.md` §5)은 이 흐름에 맞춘다.

| 문항 | 흐름 | 문항 은행의 단위 |
|---|---|---|
| 1 | 자기소개 | 주제 `자기소개` |
| 2~7 | 설문에서 고른 주제 3문항 묶음 2개 | 설문조사 주제(설문 연결로 고른 항목에 이어짐) |
| 8~10 | 돌발 주제 3문항 묶음 | 돌발질문 주제 |
| 11~13 | 롤플레이: 질문하기 → 문제 해결·대안 → 관련 경험 | `롤플레이: 이름` 세트 3문항(등록 순서) |
| 14~15 | 한 주제의 과거·현재 비교 → 사회 이슈·의견 | `고난도: 이름` 세트 2문항(등록 순서) |

## 유형 매핑

| 메모 표현 | 유형 |
|---|---|
| 묘사, 소개, 루틴, 언제·어디서, 보통 뭐 해 | DESCRIPTION |
| 처음·최근·기억에 남는 경험, 문제가 생긴 경험 | PAST_EXPERIENCE |
| 과거·현재 비교, 어릴 때와 지금, 두 가지 비교 | COMPARE_CONTRAST |
| 롤플레이 질문하기, 문제 해결·대안 제시 | ROLE_PLAY |
| 14·15번 이슈·우려·의견 | OPINION |

- 설문·돌발 주제는 묘사 → 경험 → 비교가 섞이도록 3~8문항을 둔다. 묶음은 같은 주제의 쓰지 않은 문항이 2개 이상일 때만 나온다.
- 목표 레벨: 묘사 IL·IM·IH, 경험 IM·IH, 비교·롤플레이 IM·IH·AL, 고난도 IH·AL
- 모든 문항에 유형별 답변 구조 힌트(`structural_hint`)를 넣는다. 연습 화면에 보인다.

- 예전에 임시로 쓴 문항은 지우지 않고 **비활성화**했다. 대상은 이번 문항으로 대체된 9개 주제의 문항과 임시 롤플레이·고난도 세트다. 관리자 화면에서 다시 켤 수 있다.
- 메모에 나오지 않은 주제(TV 시청, 독서, 요리, 헬스/운동, 수영, 조깅/걷기, 출장, 이웃/동네, 약속 취소, 물건 분실, 기기 고장)의 예전 문항은 그대로 켜 두었다. 끄면 그 설문 항목을 고른 사람에게 낼 문제가 없다.

## DB에 넣는 방법 (배포할 때 한 번)

문항 원본과 스크립트는 `scripts/`(gitignore)에 있다. 운영 DB를 처음 띄울 때 같은 순서로 한 번 실행한다.

1. 서버를 한 번 띄워 테이블을 만든다(지금은 Flyway가 없어 `ddl-auto`가 만든다). 기본 설문 연결도 이때 들어간다.
2. 검증하고 SQL을 만든다: `python -I scripts/load-question-bank.py`
   - 분류, 세트 크기(롤플레이 3·고난도 2), 설문 항목 id, 연결 주제의 분류, 주제별 최소 문항 수, 중복 문장을 확인한다.
   - 결과는 `scripts/seed-question-bank.sql`이다.
3. DB를 백업한다(`pg_dump`).
4. SQL을 실행한다. 한 트랜잭션이고, 다시 실행해도 중복이 생기지 않는다.
   - 주제는 같은 제목이 없을 때만, 문항은 (주제, 문장)이 같은 것이 없을 때만, 연결은 (항목, 주제)가 없을 때만 넣는다.
   - 세트 안 순서는 `created_at`을 1초씩 늘려 지킨다.
5. 건수를 확인한다: 주제 수, 활성·비활성 문항 수, 롤플레이·고난도 세트 수, 설문 연결 수

그 뒤의 추가와 수정은 관리자 화면에서 한다. 이 스크립트를 다시 돌리면 관리자가 지운 문항이 되살아날 수 있으니, 첫 적재 뒤에는 쓰지 않는다.
