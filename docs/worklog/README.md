# Worklog

사용자 요청과 그에 따른 분석, 계획, 개발, 검증을 날짜별로 남기는 기록입니다(규칙: `AGENTS.md` §3.4).

- `plan.md`는 진행 중인 작업 메모입니다(git 제외).
- 이 디렉토리는 **커밋되는 이력**입니다.

## 파일 규칙
- 파일 하나에 작업 하나: `docs/worklog/YYYY-MM-DD-<short-slug>.md`
- 같은 작업이 이어지면 그날 파일에 덧붙입니다. 날짜가 바뀌면 새 파일을 만들고, 앞 파일을 링크합니다.
- 요청을 받았을 때 작성하고, 마무리(Close Out) 때 결과를 갱신합니다.
- 비밀값(API 키, 토큰, 비밀번호)과 개인정보는 절대 쓰지 않습니다. 필요하면 `[REDACTED]`로 씁니다.

## 템플릿

```markdown
# <작업 제목>

- 날짜: YYYY-MM-DD
- 관련: 이슈 #, PR #, 계획 파일 경로

## 사용자 요청 (원문)
> 사용자가 보낸 프롬프트를 그대로 옮깁니다. 여러 번이면 시간 순으로 모두 적습니다.

## 분석
- 현재 상태와 문제, 근거(파일 경로)

## 결정 / 계획
- 사용자 결정, 선택한 방식과 이유, PR 분할

## 진행 / 결과
| PR | 내용 | 검증 |
|---|---|---|

## 남은 일 / 후속
- 다음 단계, 미확인 항목, 열린 질문
```
